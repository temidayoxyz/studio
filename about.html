The method

Fifty sites,
one pipeline,
no shortcuts.

Every site in the index passed through the same gate — and none of them look like it.

01

Concept & brand

A business, a city, a voice. Each project starts as a brief — who they are, who they serve, and what makes them worth visiting.

02

Design system

Palette, typography pair, imagery strategy and motion language — chosen per project, never reused, never templated.

03

Build & test

A self-contained Vite site, responsive from 390 to 1280 pixels, accessible, with working forms and a tested mobile menu.

04

Ship & verify

Git repository, GitHub Pages, live URL. Every deployment is verified — the index only lists sites that return 200.

The rules

Kept for all fifty.

04
