The method

The same four stages. No shared stylesheet.

Every site in the index went through the same gate, and none of them came out the same way. This is what the gate actually checks — and what it rejects.

01 — The pipeline

Four stages, in order.

The stages are fixed. Nothing that happens inside them is — that is the whole point of running them the same way fifty times.

  1. Stage one

    Name it before you style it

    A business, a place, a customer and a name that could only belong to this one. If two projects could swap wordmarks and still look right, the naming is not finished.

    • Who it is for, and what they arrive already knowing
    • The one sentence the whole site has to earn
    • A name, checked against what already exists

  2. Stage two

    Decide the system, write it down

    Palette, type pairing, imagery rules, spacing, motion language and the grid — chosen for this project and written into tokens before a single section gets built.

    • Contrast checked before anything is approved
    • Motion limited to what the content actually needs
    • No token carried forward from the last project

  3. Stage three

    Build it as one self-contained site

    Semantic markup, real forms, keyboard-reachable navigation, and a layout that is fluid rather than a desktop design with a breakpoint bolted on.

    • Checked at 390, 768, 1280 and 1920 px
    • No horizontal scroll at 320 px
    • Touch targets sized for smaller hands

  4. Stage four

    Ship it alone, then verify it

    Its own repository, its own build, its own URL. The site only enters the index once the deployment answers for itself — not because the build finished.

    • One repository per project, no shared runtime
    • Deployed URL fetched and checked, not assumed
    • The check re-run before each site is listed

02 — The standard

Six rules. No exceptions.

The six rules every project must pass, and how each was checked.
Number The rule How it was checked
01 Its own name, palette, type and voice Fifty separate identities — no two projects could swap wordmarks and still look right.
02 No template, no copied layout, no shared stylesheet All fifty compiled stylesheets are byte-unique. Sixty-two typefaces are in use across the set.
03 Responsive from 390 px to 1920 px Fluid layouts checked at 390, 768, 1280 and 1920 px on every build.
04 Semantic markup, labelled controls, visible focus Landmarks, heading order, form labels, focus states and keyboard reach audited on each build.
05 Its own repository and its own deployment Fifty repositories, fifty URLs, and no runtime shared between any two of them.
06 It answers 200 before it enters this index All fifty re-fetched and confirmed on 25 September 2026.
